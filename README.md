# IT415 Touchscreen POS Kiosk

A touchscreen Point of Sale kiosk project for the IT415 Practical Examination.
The current stage provides only the basic project foundation and application initialization.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Getting started

Open `index.html` in a web browser. No installation or build step is required.

## Project structure

- `index.html` — application page
- `style.css` — basic page styling
- `script.js` — safe application initialization
- `docs/` — project documentation directory
